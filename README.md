# 🧮 CodeAlpha Calculator

A simple, responsive, and user-friendly calculator built using **HTML, CSS, and JavaScript**.

This project was developed as part of my **CodeAlpha Frontend Development Internship** to practice frontend development fundamentals, JavaScript functionality, and responsive web design.

## 🚀 Live Demo

**Live Website:**
https://urooba445.github.io/CodeAlpha_Calculator/

## 📌 Features

* Basic arithmetic operations
* Addition, subtraction, multiplication, and division
* Clear/reset functionality
* Responsive design
* Clean and simple user interface
* JavaScript-based calculations
* Works on desktop and mobile devices

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive layout
* **JavaScript** – Calculator functionality and calculations

## 📂 Project Structure

CodeAlpha_Calculator/

## 💻 How to Run Locally

1. Clone this repository:

```bash
git clone https://github.com/urooba445/CodeAlpha_Calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! The calculator will run directly in your browser.
